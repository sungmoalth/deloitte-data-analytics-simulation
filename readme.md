# 📊 Deloitte Data Analytics Job Simulation

## Overview
This project was completed as part of the **Deloitte Australia Data 
Analytics Job Simulation (2026)**, hosted on Forage. The simulation 
provided hands-on experience in data analysis and visualisation 
within a real-world consulting context.

## Simulation Tasks
- Analysed factory equipment health data across multiple global 
  locations (Berlin, Meiyo, Seiko, Shenzhen)
- Identified unhealthy device patterns by factory and device type
- Built an interactive dashboard to communicate findings to 
  stakeholders

## Key Findings
- **daikibo-factory-seiko** and **daikibo-shenzhen** recorded the 
  highest number of unhealthy device incidents
- **LaserCutter** was the most frequently unhealthy device type, 
  significantly outperforming all other equipment categories
- These findings suggest targeted maintenance prioritisation for 
  Seiko and Shenzhen facilities, particularly for laser cutting 
  equipment

## Tools Used
- **Tableau** — interactive dashboard and data visualisation
- Data analysis and pattern identification across multi-site 
  manufacturing data
